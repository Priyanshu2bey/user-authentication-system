# User Authentication System

A full-stack user authentication system built with Spring Boot, Spring Security, JPA/Hibernate, MySQL, and a frontend interface.

## 🚀 Features

- User registration
- User login
- Secure authentication
- Password management
- MySQL database integration
- JPA/Hibernate ORM
- REST API based backend
- Frontend authentication interface
- Environment-based database credentials
- Maven project management

## 🛠️ Tech Stack

### Backend
- Java 21
- Spring Boot 4
- Spring Security
- Spring Data JPA
- Hibernate
- Maven
- REST APIs

### Database
- MySQL 8

### Frontend
- HTML
- CSS
- JavaScript
